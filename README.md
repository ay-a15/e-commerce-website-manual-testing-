# E-Commerce Web Testing Project

## Overview
Manual QA testing project performed on [saucedemo.com](https://www.saucedemo.com), a sample e-commerce web application. The goal of this project was to design and execute a comprehensive set of manual test cases covering core e-commerce user flows, identify and document defects, and produce supporting QA documentation (test plan and test summary) to demonstrate end-to-end manual testing skills.

## Scope
Testing covered the following functional areas:
- Login
- Product Inventory page
- Product Info pages
- Shopping Cart
- Checkout: Step One
- Checkout: Step Two
- Checkout: Complete
- Logout

## Test Artifacts
| File | Description |
|------|-------------|
| `EC test plan.docx` | Defines testing scope, approach, objectives, and resources for the project |
| `EC test cases.docx` | 43 manual test cases covering login, logout, cart, inventory, product info, and all checkout steps |
| `EC bug reports.docx` | 5 documented defects found during test execution, including steps to reproduce, severity, and priority |
| `EC test summary report.docx` | Summary of testing activities, results, and overall quality assessment |

## Tools Used
- Manual testing (browser-based)
- Microsoft Word — test plan and test summary documentation
- Chrome DevTools — supporting investigation during testing

## Key Findings
- **43** test cases written and executed
- **5** bugs identified and logged
- Coverage across 8 functional areas of the application, from authentication through full checkout completion

## Skills Demonstrated
- Manual test case design (positive, negative, and edge-case scenarios)
- Defect identification, logging, and reporting
- Test planning and test summary reporting
- E-commerce domain testing (cart, checkout, inventory flows)
- Attention to detail across multi-step user journeys
